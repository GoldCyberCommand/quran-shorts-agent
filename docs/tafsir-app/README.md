# Bayān — planning documents

Planning for a comprehensive English Qur'an tafsīr app. The objective is to bring the
depth of the Sunni tafsīr tradition within reach of both the layman and the serious
student: for every ayah, a plain-English summary, the context of revelation, and the
full range of widely accepted Sunni scholarly views — each attributed, cited, and
connected to the other verses scholars reach for when explaining it.

**Sunni Islam only**, declared openly rather than assumed.

This is a **separate product** from `quran-shorts-agent` (the video tool this repo
contains). The planning docs live here for now; the project should graduate to its own
repository before Phase 0 — see PLAN.md §15.
