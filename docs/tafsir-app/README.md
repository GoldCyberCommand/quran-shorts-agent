# Bayān — planning documents

Planning for a comprehensive English Qur'an commentary app: for every ayah, a plain-English
summary, the context of revelation, and the full range of Sunni scholarly views, each
attributed and cited.

This is a **separate product** from `quran-shorts-agent` (the video tool this repo
contains). The planning docs live here for now; the project should graduate to its own
repository before Phase 0 — see PLAN.md §13.

| Document | What it covers |
|---|---|
| [PLAN.md](PLAN.md) | The plan: product shape, content architecture, pipeline, tech stack, phasing, costs, risks |
| [SOURCES.md](SOURCES.md) | Every text we use, its licence, and whether it can ship. **The release gate.** |
| [EDITORIAL-POLICY.md](EDITORIAL-POLICY.md) | The rules governing what the app is allowed to say |

**Start here:** PLAN.md §3 (the finding that reshapes the scope) and §10 (the real
constraint — review capacity, not engineering).
